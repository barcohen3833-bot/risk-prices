מדיניות פרטיות

בקצרה: אפשר לראות את כל המחירים בלי למסור שום פרט. אנחנו שומרים מידע אישי רק כשמשאירים פרטים לשיחה עם סוכן, ולא מוכרים אותו.

בקשה לשיחה עם סוכן

כששולחים את הטופס "שיחה עם סוכן", נשמרים השם, הטלפון, המייל (אם מילאת), ההערות והביטוח שבחרת (גיל, מין, עישון, סכום, חברה ומחיר). המידע נשמר במסד נתונים מאובטח ב-Supabase, ומועבר לסוכן ביטוח מורשה אחד בלבד, שרואה רק את הפניות שהופנו אליו. הסוכן עשוי להעביר את פרטי הביטוח למפיק בחברת הביטוח כדי להכין הצעה. המידע משמש רק לחזרה אליך עם הצעה. לבקשת מחיקה: דף הפניות (בלי לפרסם שם פרטים אישיים).

מה נשמר במכשיר שלך

  • העדפות תצוגה (גיל, מין, סכום, מצב כהה, הגדרות נגישות) ואחוזי ההנחה שבחרת, באחסון המקומי של הדפדפן (localStorage). המידע לא יוצא מהמכשיר, ואפשר למחוק אותו בניקוי נתוני האתר בדפדפן.
  • סוכנים מחוברים: אסימון הכניסה נשמר במכשיר עד היציאה.
  • פרטי סוכן בטופס הקמת פוליסה נשמרים רק אם סימנת "לזכור את פרטי הסוכן".
  • פרטי הלקוח בטופס (שם, תעודת זהות, טלפון וכו') לא נשמרים בכלל, ונמחקים כשסוגרים את הדף או לוחצים "ניקוי פרטי לקוח".

שליחת פרטים

כשלוחצים "שליחה בוואטסאפ" או "שליחה במייל", האתר פותח את האפליקציה שלך עם הטקסט מוכן, ואת/ה מחליט/ה אם לשלוח. מאותו רגע המידע כפוף למדיניות של וואטסאפ או של ספק המייל. יש לקבל את הסכמת הלקוח לפני העברת פרטיו.

שירותים חיצוניים

  • GitHub Pages מאחסן את האתר, ועשוי לרשום כתובות IP לצורכי אבטחה (מדיניות GitHub).
  • Google Fonts מספק את הגופנים, והדפדפן פונה לשרתי Google כדי להוריד אותם.

Supabase משמש גם לכניסת הסוכנים. אין באתר עוגיות, פרסומות או כלי מעקב וסטטיסטיקה.
